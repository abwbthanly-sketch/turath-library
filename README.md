# المكتبة التراثية

موقع ثابت (HTML) يُنشر على Firebase Hosting. الكتب في `books/` بصيغة `.json.gz`.

- النصوص من OpenITI بترخيص CC BY-NC-SA 4.0.
- لا تضع مفاتيح API في المستودع. مفتاح الباحث الذكي يلصقه كل مستخدم في متصفحه.
- كل دفعة إلى `main` تُنشر تلقائيًا على Firebase عبر GitHub Actions.

## طريقة التعديل
1. عدّل الملف على GitHub مباشرة (زر القلم ✏️) أو على جهازك ثم `git push`.
2. كل دفعة إلى `main` تُنشر تلقائيًا على https://turath-library-abw.web.app خلال دقيقة إلى ثلاث.
3. تابع حالة النشر من تبويب **Actions** في المستودع.
